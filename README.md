# FESTORA — Our Onam Story — Device-Safe Mobile Final

This build fixes the real-phone issue where the browser can report a wider CSS viewport than the phone's physical width.

## Mobile behavior
- Uses a dedicated vertical mobile hero background
- Never relies on the desktop banner for mobile text
- FESTORA / Our Onam Story / 2026 Onam Celebration scale responsively
- Mobile hamburger menu
- One-column responsive celebration gallery
- Responsive 4:5 photo cards
- Captions directly over photos, no boxes
- Touch-friendly full-screen photo viewer
- No horizontal page overflow
- Mobile mode also activates for touch/coarse-pointer devices and tablet-sized CSS viewports
